# Fabrice Tamaffo — Portfolio

Responsive personal portfolio with a clean light theme, accessible navigation, and instant English/French translation. Uses plain HTML, CSS and JavaScript; no npm or backend required.

## Local preview
Open `index.html` in your browser or right-click the file in Visual Studio Code and select **Open with Live Server**.

## Deploy to GitHub Pages
Upload the contents of this folder (not a ZIP file) to a public GitHub repository. Make sure `index.html`, `style.css`, `script.js`, and the `assets` folder are at the root of the repository. In **Settings → Pages**, choose **Deploy from a branch**, **main**, **/(root)**. Wait for the website URL to appear.

## Editing
Edit HTML in `index.html` and translations in `script.js` (both `en` and `fr`). Styles are in `style.css`. The portrait is at `fabrice-profile.png`, and the linked CV is at `assets/fabrice-cv.pdf`. No absolute local Windows paths are used.
